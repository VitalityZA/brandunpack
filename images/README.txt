BRANDUNPACK — IMAGE DROP FOLDER
================================

automatically. If a file is missing, the colored placeholder shows instead
(with a small "drop: <name>.jpg" hint), so nothing ever breaks.

All files must be .jpg (lowercase). Use the exact names below.

TIPS
- Sizes above are the recommended export sizes (already 2x for sharp
  display on retina screens). Bigger is fine; smaller may look soft.
- Images are cropped to fill ("cover"), centered. Keep the important
  part near the center.
- Keep file sizes reasonable (under ~400 KB each) so the site loads fast.
