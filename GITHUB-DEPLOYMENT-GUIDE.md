## 📋 Step-by-Step Instructions

### Step 1: Find Your GitHub Repository

1. **Go to GitHub:** https://github.com
2. **Sign in** to your account
3. **Find your repository** (probably named something like `brandunpack`, `brandunpack.github.io`, or similar)
4. **Click on it** to open the repository

---

### Step 2: Download Your New Website Files

1. **Download these 2 files** from our chat:
   - ✅ `index.html` (your new website)
   - ✅ `miriska-harris.jpg` (profile photo)

2. **Save them** to your Desktop or Downloads folder
   - Keep them together in the same location
   - Make sure they're downloaded completely

---

### Step 3: Delete Old "Under Construction" File (Optional)

**If you want to clean up first:**

1. In your GitHub repository, find your old `index.html` file
2. Click on it
3. Click the **trash can icon** (🗑️) at the top right
4. Scroll down and click **"Commit changes"**
5. Click **"Commit changes"** again in the popup

**Or you can skip this and just replace it in the next step!**

---

### Step 4: Upload Your New Website Files

**Method A: Drag & Drop (Easiest)**

1. In your GitHub repository, make sure you're on the main page
2. **Drag both files** (`index.html` + `miriska-harris.jpg`) directly into the file list area
3. GitHub will show an upload interface
4. Add commit message: `"Launch new BrandUnpack website"`
5. Click **"Commit changes"**

**Method B: Upload Files Button**

1. Click **"Add file"** button (top right)
2. Click **"Upload files"**
3. Click **"choose your files"** or drag files into the box
4. Select both `index.html` and `miriska-harris.jpg`
5. Commit message: `"Launch new BrandUnpack website"`
6. Click **"Commit changes"**

---

### Step 5: Wait for Deployment (1-2 Minutes)

1. **Click "Actions"** tab at the top of your repository
2. You'll see a workflow running (yellow dot 🟡)
3. Wait for it to turn into a green checkmark ✅ (usually 30-90 seconds)
4. This means your site is live!

---

## 🔧 If Something Goes Wrong

### **"404 - Page Not Found"**
**Solution:** Wait 2-3 minutes and refresh. GitHub Pages takes a moment to build.

### **"Photo not showing (broken image)"**
**Solution:** 
1. Make sure both files are uploaded to the same folder
2. Check the file is named exactly: `miriska-harris.jpg` (lowercase, no spaces)
3. Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)

### **"Old 'under construction' page still showing"**
**Solution:**
1. Hard refresh browser: **Ctrl+Shift+R** (Windows) or **Cmd+Shift+R** (Mac)
2. Or clear browser cache completely
3. Wait 2-3 minutes for GitHub to rebuild

### **"Website not updating after upload"**
**Solution:**
1. Check Actions tab - make sure deployment completed (green checkmark)
2. Clear browser cache
3. Try in incognito/private browsing window

## 🌐 Custom Domain (If You Have One)

If you own **brandunpack.com** and want to use it:

### GitHub Settings:
1. Go to repository **Settings**
2. Click **"Pages"** (left sidebar)
3. Under **"Custom domain"**, enter: `brandunpack.com`
4. Click **"Save"**
5. ✅ Check **"Enforce HTTPS"**

### Domain Provider Settings:
Add these DNS records at your domain registrar (GoDaddy, Namecheap, etc.):

**A Records (point to GitHub):**
```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**CNAME Record:**
```
www → YOUR-USERNAME.github.io
```

**Wait 24-48 hours** for DNS to propagate globally.
