# BrandUnpack — Website

Complete, self-contained website. Fully responsive (phones, tablets, desktop).

## Add your images
Open `images/` and read `images/README.txt`. Drop in correctly-named .jpg files
(`sw1.jpg`, `rr1.jpg`, `header1.jpg`, …) and they appear automatically.

## Deploy to GitHub
Copy ALL contents of this folder into your repo root (index.html at root with
`assets/`, `tokens/`, `images/`, and the `.jsx` files). Keep CNAME, BU.png, and
Miriska.png. Commit to main → Push.

## Contact form
Wired to your Formspree (form xwvdveon). Submissions arrive in your inbox.

## SEO
The page head includes title, meta description, Open Graph + Twitter cards,
canonical URL, and Organization structured data.

## Notes
- Fonts load from Google Fonts. The brand "Broxa" font ships as outlined SVG.
- Favicon ships as SVG plus PNG fallbacks (Safari/older browsers).
